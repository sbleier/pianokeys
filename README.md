### Instructions to Test in lambda 
1. Create a request.json file in the project. 
2. In the terminal, run:

   curl -X POST \
   -v \
   -H "Content-Type: application/json" \
   -d @request.json \
   urlToYourLambda

3. To check it, open the URL in a browser and make sure what you put is there.
